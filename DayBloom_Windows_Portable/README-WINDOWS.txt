DAYBLOOM - WINDOWS DESKTOP APP

1. Extract this entire folder.
2. Open runtime\DayBloom.exe.
3. To get a WhatsApp-style desktop icon, right-click
   "Create Desktop Shortcut.ps1" -> Run with PowerShell.
4. Keep the runtime folder next to the launcher.

Includes calendar, tasks, reminders, Windows notifications, sticky notes,
themes, night mode, compact mode, system tray and local data storage.

This is a portable Windows build; it does not need Node.js installed.
